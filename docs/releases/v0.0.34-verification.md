Candidate: `0561decfeb226f772d869fe1687210a9d5f39ac7`.

The baseline tag's manifests say 0.0.32; the release workflow bumped the manifests after tagging. Feature code was compared against the tag.

No new regression was found in the checks below. The browser matrix also reproduced an existing plain contenteditable newline limitation.

The browser matrix called each checkout's actual Rust `replace_text` implementation in a dedicated bmux pane. It checked capture and geometry, then append, repeated append, replacement, Unicode, multiline text with an empty line, clearing, and quotes/backslashes. Inputs used a single-line Unicode case. All 24 edit cases across input, textarea, nested shadow textarea, and Draft.js matched the model. Textarea and shadow-textarea tests received zero Enter key events. Candidate cleanup registry entries were removed after every update.

The Vim trace covered motions, line/document navigation, operators, text objects, counts, clipboard commands, undo/redo, insertion commands, visual operations, indentation, paragraph/half-page navigation, replacement, Escape, and mode toggles. This compares generated actions and state; it is not a test of macOS key injection in every native app.

Unchanged source was also reviewed for scroll/list modes, widgets, click mode, keyboard capture, clipboard capture/paste-back, cancellation, launcher scripts, settings serialization, updater commands, and terminal adapters other than Alacritty.

[CI for the candidate](https://github.com/tonisives/ovim/actions/runs/38000725081) passed the test job and builds for `aarch64-apple-darwin` and `x86_64-apple-darwin`.

## Approval checks

Actual X and Reddit pages were not edited in this run. The controlled-editor and shadow-field fixtures check the corresponding integration paths. Before publishing, confirm popup placement and formatting-tooltip behavior on those pages, plus native-app paste-back and cancellation. Other terminal apps were compiled and reviewed but not launched. Permission retention was checked through signing tests and the installed signature; permissions were not revoked or the app reinstalled during this verification.

The draft contains release notes only. Signed/notarized distribution assets, updater archives, and Homebrew publication run after approval through the release workflow.

## Release workflow and diagnostics

The release trigger was changed from `created` to `published` so publishing the approved draft starts the pipeline. [GitHub documents this event for draft publication](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#release). Workflow YAML was parsed after the change; the publish event itself will only be exercised after approval.

`cargo clippy --all-targets -- -D warnings` failed in the unchanged `examples/test_suppress.rs` and `examples/test_suppress_raw.rs`: outdated Core Graphics callback/API usage and naming/unused-code diagnostics. These files match v0.0.33. The shipping library and binaries pass `cargo clippy --lib --bins -- -D warnings`.
