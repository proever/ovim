## Browser blinking regression follow-up

The GitHub release editor in bmux `%37` is a textarea. Its draft was inspected without changing its contents. A separate bmux pane exercised the actual Rust browser-sync path, with focus, blur, input and Enter events recorded on the fields.

The original candidate blurred the field after every update and focused it again for the next update. Five appends produced five blur events in each of input, textarea, plain contenteditable and nested-shadow textarea fixtures. Replaying v0.0.33's textarea preparation and trusted input sequence produced zero focus and zero blur events, with the correct final text. This confirms the regression against the previous release. The original matrix checked resulting text and cleanup, but did not measure focus transitions.

The fix keeps DOM focus stable and retains the selection/caret suppression between updates. It restores normal styling after the sync worker drains the final snapshot, on failed input, on a browser pointer interaction, or after the recovery timeout. Identical snapshots skip focus, selection, styles and trusted input entirely.

The corrected Rust path passed 48 edits across input, textarea, plain contenteditable, four nested shadow roots with a textarea, and React 18.3.1 / Draft.js 0.11.7. Cases cover repeated appends, replacement, Unicode, clearing, quotes/backslashes and multiline edits. Every field recorded zero focus and zero blur events after initial fixture focus. Draft.js content was checked against its React editor model after each edit. Native textareas received zero Enter key events. An unchanged snapshot left every event counter unchanged, and explicit session cleanup removed each suppression entry.

Permanent JavaScript regression checks cover repeated-update focus stability, suppression reuse, unchanged snapshots, explicit cleanup, returning to the browser and timeout recovery.

After the fix, the 42 Rust library/binary tests and 14 JavaScript tests passed. Clippy for the shipping library and binaries passed with warnings denied.
